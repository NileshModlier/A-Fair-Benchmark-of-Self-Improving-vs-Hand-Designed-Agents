Overview
Claims that self‑improving agents outperform humans often rely on:

Unequal compute
Different evaluation criteria
Hidden tuning advantages

This project establishes a fair, normalized comparison framework.

Method

Identical compute budgets
Identical task access
Identical time constraints
Controlled evaluation noise

Agent types compared:

Hand‑designed
DGM‑style
Hyperagents
Human‑in‑the‑loop


Findings

Self‑improvement excels in long‑horizon tasks
Humans outperform on short, structured tasks
Some self‑improving systems show instability


Contribution
This repository emphasizes scientific honesty over hype.
